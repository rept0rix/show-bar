Stop running 5 separate paid menu-bar utilities. Show Bar brings Windows-style Dock window previews, a real window-level Command-Tab switcher, fast window snapping, visual clipboard history, and a floating screenshot markup shelf into one ultra-lightweight, 100% free native macOS app.

Built natively in Swift and SwiftUI, Show Bar uses under 30MB of RAM, runs with zero lag, and looks right at home on macOS Sonoma and macOS Sequoia.

5 ESSENTIAL MAC TOOLS IN ONE APP:

◆ DOCK HOVER WINDOW PREVIEWS
Hover over any running app icon in your Dock to see live, high-resolution thumbnail previews of all open windows. Switch to, minimize, or close specific windows right from the preview card. Supports bottom, left, and right Dock placements across multiple monitors and Spaces.

◆ WINDOWS-STYLE COMMAND-TAB SWITCHER
macOS Command-Tab only switches between app icons; Show Bar switches between actual open windows. Instantly spot the exact browser window, document, or project you need with live visual thumbnails.

◆ KEYBOARD WINDOW SNAPPING & TILING
Organize your workspace in a single keystroke. Snap windows into left/right halves, quarters, thirds, or fullscreen using clean keyboard shortcuts (⌃⌥ + Arrow keys) or the menu bar.

◆ VISUAL CLIPBOARD HISTORY (⌃⌥V)
Never lose copied text, code snippets, links, or images again. Open your visual clipboard shelf with a shortcut, fuzzy-search past copies in milliseconds, and paste them right back.

◆ FLOATING SCREENSHOT SHELF & MARKUP
Capture your screen and keep recent shots pinned in a corner shelf. Annotate with arrows, text, shapes, blur, and crop, or batch-copy multiple screenshots at once.

## App Review Notes

Show Bar is a native local macOS utility. The reviewer can test all features without an account or network connection.

1. **Window Previews & Dock Hover:** Requires Screen Recording consent to draw live window thumbnails via ScreenCaptureKit, and Accessibility consent to inspect Dock hover position.
2. **Window Snapping & Switcher:** Uses Accessibility APIs to position windows into halves/corners upon user shortcut.
3. **Screenshots & Clipboard:** Fully local on-device utility.
4. **App Privacy:** Show Bar does not track personal identifiers (PII). Anonymous usage milestones (e.g. app launched, feature invoked) may be gathered to diagnose onboarding issues in full compliance with Apple's diagnostic disclosures.
