# כיסוי פיצ׳רים, הגדרות והרשאות

עודכן: 30 באוקטובר 2026. ״מומש״ מתייחס לקוד ולבדיקות המתועדות; הרשאות, פעולות חלון וציוד פיזי עדיין דורשים בדיקה במכשירים אמיתיים לפני הפצה.

| תחום | מה קיים | גבולות או עבודה שנותרה |
| --- | --- | --- |
| חיבור | גילוי מק ברשת, צימוד מוצפן, שמירה ב־Keychain, ניתוק וחיבור מחדש | החיבור פעיל כשהאפליקציה בחזית |
| שליטה בחלונות | בחירה, מעבר, 9 אזורי סידור, סגירה, אישור סגירה הניתן להגדרה | דורש Accessibility; נדרשת בדיקה בחלונות אמיתיים ובכמה מסכים |
| הרשאות לפיצ׳רים | בקרות נפרדות למעבר, סידור, סגירה, כתיבה ללוח והדבקה | המדיניות נאכפת במק; מכשיר נלווה אינו יכול להעניק לעצמו גישה |
| שיתוף תוכן | בקרות נפרדות לטקסטים, תמונות לוח, תצוגות חלונות וצילומי מסך | תמונות לוח דורשות גם הרשאת שיתוף לוח |
| הגדרות באייפון ובאייפד | מסך ייעודי, מצב הרשאות מערכת ויכולות, אישור סגירה, הצגת תצוגות מקדימות, מצב שולחן, ניקוי מדף ושכחת צימוד | מצב דמו או ניתוק אינם מוצגים כאישור הרשאות מערכת |
| לוח טקסטים | מדף מק, מדף מקומי, הוספה מפורשת, חיפוש וסינון, העתקה והדבקה לחלון נבחר | 20 פריטים מרוחקים ו־100 מקומיים לכל היותר; תצוגות טקסט מקוצרות מסומנות ולא נשלחות כאילו הן המקור המלא |
| תמונות לוח | תצוגות מקדימות, הורדת PNG שמור, העתקה, עריכה ושיתוף מהמק למכשיר | הורדה מפורשת, עד 3 MiB ועד 4000 פיקסלים בכל ציר; אין העלאת תמונות בחזרה למק |
| צילומי מסך | מדף מק, הורדה, העתקה/שיתוף של כמה צילומים, גרירה ועריכה ב־PencilKit | עותקי JPEG עד 2400 פיקסלים ו־3 MiB; לא העברת מקור ללא אובדן |
| מקלדת | ⌘1–4 לניווט; ⌥⌘ עם חצים/Return או U/I/J/K לסידור חלון מק מתוך מסך Windows | אין החלפה של מחליף האפליקציות המערכתי של האייפד |
| ניהול חיבורים ומכשירים | זיהוי קבוע (deviceID ייחודי לכל מכשיר), רשימת מכשירים מצומדים ופעילים, ביטול גישה (Revoke) פרטני למכשיר בודד ללא צורך באיפוס הקוד לכולם, ניתוק מכשיר בודד, וממשק הגדרת הרשאות מותאמות (Custom Capabilities) ישירות במק עם פריסטים (Guest/Read-Only, Window Control, Full Access) ו־9 מתגים פרטניים | הגדרות המק הכלליות משמשות כתקרה ביטחונית (Ceiling); שינוי הגדרה או חסימה מנתק מיידית או מעדכן בזמן אמת |
| ייבוא מאפליקציות אחרות | כפתור Paste מפורש, רישום תבנית URL Scheme מערכתית (showbar://shelf/add?text=... ו־url=...) לייבוא ישיר מכל אפליקציה ו־Shortcuts | פתיחת האפליקציה מייבאת ושומרת ישירות למדף המקומי ומציגה משוב |
| יכולות מערכת iPadOS | שימוש באפליקציה ובפריסה המסתגלת לשטח הזמין | מעקב אוטומטי אחר הלוח ברקע, שכבה מעל אפליקציות אחרות והחלפת ⌘Tab אינם חלק מהמימוש הרגיל הנתמך |

סגירת חלונות, כתיבה/הדבקה למק וכל קטגוריות השיתוף כבויות בתחילה. מעבר וסידור חלונות זמינים לאחר הפעלה מפורשת של החיבור במק. שינוי הגדרה חוסם בקשות עתידיות, מבטל בקשות אסורות שעדיין ממתינות ומסיר מידע שאינו מותר מהמצב המרוחק. הוא אינו מוחק עותק שכבר יוצא ונשמר במכשיר אחר.

אין כאן הצהרה על שוויון מלא לכל אפשרות של אפליקציית המק. הפערים המפורטים בטבלה נשארים גלויים עד למימוש ולבדיקה.
